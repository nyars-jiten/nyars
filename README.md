**НЯРС** (**Н**овый **Я**понско-**Р**усский **С**ловарь) / **NYARS** (New Japanese-Russian Dictionary) – японско-русский онлайн словарь, основная цель которого дать пользователям возможность самим добавлять и исправлять статьи.

## Getting started

```sh
# Clone the repo
git clone https://github.com/nyars-jiten/nyars
cd nyars

# Install dependencies
bun i

# Start local server with hot-reload
bun dev
```
